# 🚀 Career Compass

Career Compass is a responsive frontend web application designed to help students streamline their career preparation. It provides a centralized dashboard for tracking internship applications, monitoring skill development, and exploring AI-powered career recommendations through an intuitive and modern user interface.

## ✨ Key Features

- Responsive and mobile-friendly interface
- Interactive dashboard with sidebar navigation
- Internship application tracking
- Skill progress monitoring
- AI-powered career recommendations
- Modern glassmorphism-inspired UI
- Smooth animations and hover interactions

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

Project Objective

The objective of Career Compass is to simplify the internship and career planning process for students by providing a clean, responsive, and user-friendly interface that helps them stay organized and monitor their professional growth.

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/Career-Compass.git
```

2. Navigate to the project directory.

3. Open `index.html` in your preferred browser.
